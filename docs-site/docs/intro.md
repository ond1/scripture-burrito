# Scripture Burrito Schema Reference

Scripture Burrito is a manifest format for Bible-related digital content. These pages document the JSON Schema that defines valid Scripture Burrito metadata.

## Key Schemas

- [Metadata](./schema/metadata) — the root object; entry point for all burrito metadata
- [Type](./schema/type) — flavor routing and content type identification
- [Identification](./schema/identification) — canonical identifiers and upstream provenance
- [Ingredients](./schema/ingredients) — file inventory
- [Languages](./schema/languages) — language tagging
- [Agencies](./schema/agencies) — publishing agencies
- [Copyright](./schema/copyright) — rights and licensing
